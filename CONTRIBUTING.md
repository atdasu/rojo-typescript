# Contributing

This template is maintained for our own projects and does not accept outside
contributions. Pull requests and feature requests will be closed without review.

You are welcome to fork it or click **Use this template** and change anything you
like; the [MIT License](LICENSE) allows it.

Security problems are the one exception: please report them privately as described
in [SECURITY.md](SECURITY.md).

If you created your own repository from this template, replace this file with your
project's contribution rules.
