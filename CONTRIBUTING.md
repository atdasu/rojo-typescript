# Contributing

This template is maintained for our own projects and does not accept outside
contributions. Pull requests will be closed without review.

Bug reports and suggestions are welcome through the issue forms, with no promise
that a suggestion is adopted.

You are welcome to fork it or click **Use this template** and change anything you
like; the [MIT License](LICENSE) allows it.

Report security problems privately, as described in [SECURITY.md](SECURITY.md),
not in a public issue.

If you created your own repository from this template, replace this file with your
project's contribution rules, and point `.github/ISSUE_TEMPLATE/config.yml` at
your own repository.
