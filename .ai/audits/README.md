# Audits

Dated evidence: test receipts, measurements, playtest results and screenshots.

- One file per audit, named `YYYY-MM-DD-topic.md`. Put bulky data beside it with
  the same prefix.
- State the scenario, what was observed, and what was not verified. Keep failures
  as well as passes.
- Say which kind of evidence it is: offline test, UI Labs story, Studio playtest
  or a person's acceptance.
- Never rewrite an audit. If it is wrong or outdated, write a new one.
